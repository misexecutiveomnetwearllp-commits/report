First-time setup
  1. Open your Google Sheet, then Extensions -> Apps Script.
  2. Replace the contents of Code.gs with the supplied Code.gs file into it.
  3. CONFIG.API_KEY to a long random string of your own.
  4. Deploy → New deployment → Web app; “Execute as: Me”, “Who has access: Anyone” → Deploy.
  5. Jo /exec URL you receive, paste it above with your API key, and click Connect.

"Anyone" is required so the browser can request data without a Google login. Without the correct API key the script returns nothing.
